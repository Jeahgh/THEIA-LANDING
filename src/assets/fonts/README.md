# Fuentes locales

Montserrat y Nunito variables, estilo normal y subconjunto Latin, descargadas
de Google Fonts el 14 de octubre de 2026. Conservan las familias, pesos y
variables CSS usadas por THEIA. Latin incluye los caracteres del español.

Las copias locales eliminan las solicitudes HTTP de `next/font/google`
durante la compilación. No se descargan fuentes al construir ni al arrancar.

Fuentes originales:

- https://fonts.googleapis.com/css2?family=Montserrat:wght@100..900&display=swap
- https://fonts.googleapis.com/css2?family=Nunito:wght@200..900&display=swap
